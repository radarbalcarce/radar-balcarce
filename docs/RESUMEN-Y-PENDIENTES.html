1. Lo que se hizo (22 y 23 de octubre)

  • Mudanza a Cloudflare, completa.La web, las tareas chicas, las redes y el video corren desde Cloudflare. GitHub quedó para guardar código y datos. Costo nuevo: US$ 0.
  • Lo de Balcarce ya no se frena por palabras sensibles.Sólo frena el rojo (abuso, suicidio, femicidio) y los avisos fúnebres. Cada vez que se libera una nota queda anotada la palabra, para medir.
  • Una nota, un solo formato.Lo que contó un repaso no va como posteo de Facebook, y lo posteado no entra en un repaso.
  • Fotos con IA renovadas.Modelo FLUX (más nítido y rápido), objetos de hoy y luz clara. El prompt de cada imagen lo escribe la IA gratis de Cloudflare. El control de la imagen usa un modelo gratis de OpenRouter. Hoy pasan el control 5 de 10.
  • Menos mails.El informe diario sale corto y dice cuántas visitas son de Argentina. El vigilante repite avisos cada 24 horas y no manda el «se arregló».
  • Documentos limpios.Se sacaron las contradicciones (Facebook, «fuentes consultadas», ejemplos, tiempos). Hay una página con todas las reglas y prompts reales.
  • Pruebas estables.Dos pruebas que fallaban según la hora ya no dependen del reloj. Pasan las 2.937.
  • Archivo en R2 cargando solo.1.124 notas guardadas y comprobadas. Todavía no se enciende la ruta pública (ver mis pendientes).
  • Datos nuevos para decidir.web/data/muy-contadas.json guarda los hechos de 8 o más medios que no salen, con título y motivo. Se llena con las próximas vueltas.
